## Technical Notes

### Camera Frame Convention

- **X**: Right (from camera's perspective)
- **Y**: Down (gravity direction when camera is upright)
- **Z**: Forward (optical axis, depth direction)

### TCP Frame Convention

- **X**: Forward (robot forward direction)
- **Y**: Left
- **Z**: Up (opposite gravity)

### Transform Usage

```python
# Camera point to TCP point
tcp_point = HAND_EYE_MATRIX @ camera_point_homogeneous

# TCP point to camera point
camera_point = np.linalg.inv(HAND_EYE_MATRIX) @ tcp_point_homogeneous
```
